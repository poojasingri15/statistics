Mathematical Formulation

P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}

Used extensively in machine learning for binary classification metric expectations, Bernoulli trials modeling, and hypothesis testing (e.g., A/B testing conversion rates).

Mathematical Formulation & AIML Context

P(X = k) = (1 - p)^{k-1} p

The geometric distribution models the number of trials until success. In reinforcement learning and search algorithms, it represents search steps or episode lengths with constant termination probability.
